## Dependency rules

Checkstack enforces strict package boundaries — these are checked by the
custom ESLint rule `checkstack/enforce-architecture-deps`:

- **Common → Common** only.
- **Frontend → Frontend or Common.**
- **Backend → Backend or Common.**
- ❌ Common may **not** depend on Backend or Frontend.
- ❌ Frontend may **not** depend on Backend.

See [Dependency Linter](/checkstack/tooling/dependency-linter/) for enforcement details.
